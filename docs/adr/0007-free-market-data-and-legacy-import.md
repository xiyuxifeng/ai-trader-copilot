# ADR-007：免费行情与旧数据迁移边界

状态：Accepted

## 决策

v1 只使用不要求付费订阅的行情来源。旧电脑历史数据通过清单、校验和、隔离区和确定性导入一次性迁移；它不是运行时依赖。

BaoStock 和 AKShare 只能作为可替换供应商适配器。任何来源在通过覆盖、复权、交易状态、可用时点和稳定性验证前都不能成为正式数据集来源。

## 原因与后果

免费接口可能限流、变更或短暂不可用，因此系统必须保存本地不可变数据版本、增量更新并明确失败。v1 仅承诺收盘后的日线研究；免费源无法可靠提供的盘中实时、Level-2 和逐笔数据不进入范围。

旧数据可能节省下载时间，但来源、复权和时点不清楚会污染回测。导入流程默认隔离并阻断，而不是猜测字段含义。
