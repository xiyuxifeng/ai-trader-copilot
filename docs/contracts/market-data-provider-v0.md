# MarketDataProvider v0

状态：`Frozen for P0 evaluation`

## 范围

v0 只覆盖 A 股和相关指数的日线研究数据，不承诺分钟线、逐笔、Level-2 或盘中实时交易。

供应商适配器必须提供：

- 未复权日线 OHLC、前收盘、成交量和成交额；
- 交易日历；
- 独立复权因子；
- 数据源名称、源版本和抓取时间；
- 明确错误，不得用缓存、零值或另一来源静默伪装成功。

规范证券代码使用 `600000.XSHG`、`000001.XSHE`、`920000.BJSE`。日期使用交易所当地日期，时间戳必须带时区。

规范成交量单位为“股”，成交额单位为人民币元。来源使用“手”时必须在适配器内乘以 100，并记录 `volume_resolution=100`；精确到股的来源记录为 `1`。交叉对账按来源精度判断，单位或精度无法证明时禁止发布。

## 时点政策

- 优先保存供应商报告的 `available_at`。
- 免费日线源没有报告发布时间时，标记为 `conservative_policy`，并按下一自然日 00:00（Asia/Shanghai）可用处理。
- 无法证明可用时点时标记为 `unknown`，禁止进入回测和建议。
- 回测信号不得在日线收盘前看到当日完整日线。

## 质量门

进入正式数据集前必须通过：

- 证券代码和 Schema；
- `(instrument_id, trading_date)` 唯一性；
- 交易日历一致性和至少 98% 的预期覆盖；
- OHLC 关系、正价格、非负成交量与成交额；
- 停牌与成交活动一致性；
- 可用时间和时区检查；
- 文件校验和与数据集清单。

任何错误都会阻止发布数据集。警告可以保留，但必须进入质量报告。

## 供应商切换

免费来源不作为领域模型的一部分。适配器可以替换，但新来源必须用同一固定样本通过质量门和交叉对账。运行中不得因为一个来源失败而无提示地切换到另一套口径。
